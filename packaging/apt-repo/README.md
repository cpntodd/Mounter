# APT Repository for Mounter
#
# This directory contains the structure for hosting an APT repository
# via GitHub Pages or any static HTTP server.
#
# ## Setup Instructions
#
# ### 1. Build the .deb package
#
#   cd /path/to/mounter
#   sudo apt build-dep .
#   dpkg-buildpackage -us -uc -b
#
# This produces `../mounter_0.1.0-1_amd64.deb`.
#
# ### 2. Initialize the repository (first time only)
#
#   sudo apt install reprepro
#   mkdir -p repo/conf
#
# Create `repo/conf/distributions`:
#
#   Origin: Mounter Project
#   Label: Mounter
#   Suite: stable
#   Codename: trixie
#   Architectures: amd64
#   Components: main
#   Description: Apt repository for Mounter - SMB/CIFS mount GUI
#   SignWith: YOUR_GPG_KEY_ID
#
# ### 3. Add the .deb to the repository
#
#   reprepro -b repo/ includedeb trixie ../mounter_0.1.0-1_amd64.deb
#
# ### 4. Host on GitHub Pages
#
#   1. Push the `repo/` directory to a branch (e.g., `gh-pages` or `apt-repo`).
#   2. In your GitHub repo Settings → Pages, set the source to that branch,
#      root directory.
#   3. Users add your repo with:
#
#      echo "deb [signed-by=/etc/apt/keyrings/mounter.asc] https://cpntodd.github.io/Mounter trixie main" | \
#        sudo tee /etc/apt/sources.list.d/mounter.list
#
#      # Import your GPG key
#      curl -fsSL https://cpntodd.github.io/Mounter/mounter.asc | \
#        sudo tee /etc/apt/keyrings/mounter.asc
#
#      sudo apt update
#      sudo apt install mounter
#
# ### 5. Automating with GitHub Actions
#
# A GitHub Actions workflow can:
#   - Build the .deb on each release
#   - Add it to the reprepro repository
#   - Commit and push the updated repo to gh-pages
#
# See `.github/workflows/release.yml` for an example.
